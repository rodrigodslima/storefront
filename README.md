# Storefront

Projeto de exemplo que simula uma loja online, construído com foco em demonstrar comunicação entre microsserviços.  

---

## 🎯 Propósito do Projeto

Este repositório tem como objetivo servir como base para aprender e praticar técnicas de interação entre serviços backend em um cenário de e-commerce.  

Em especial, o projeto busca:

- Mostrar como implementar **comunicação síncrona** e **comunicação assíncrona** entre microsserviços.  
- Permitir a compreensão das diferenças entre essas abordagens e aplicá-las num sistema realista de loja virtual.  

---

## 🧠 Requisitos de Conhecimento

Para acompanhar bem este projeto, é ideal que você já tenha:

- Java em nível intermediário  
- Orientação a Objetos em nível avançado  
- Spring em nível intermediário  
- Experiência com APIs REST (criação e consumo)  

---

## 📚 O que será aprendido

Trabalhando com este projeto, você terá oportunidade de aplicar/entender:

- Comunicação síncrona entre serviços  
- Comunicação assíncrona (fila, evento)  
- Arquitetura de microsserviços  
- Integração de sistemas distribuídos
